# 5분 데모 대본

준비: `dev/run-all.sh` → 브라우저 `http://127.0.0.1:3200` (노트북이면 `ssh -L 3200:127.0.0.1:3200 <서버>`).
Nemotron 호출이 필요한 장면(2)은 1~2분 걸리므로, 발표 전에 한 번 돌려 두고 발표 중에는 세션 목록에서 연다.

## 0:00 — 문제 (Overview)
- "온도에 민감하고 유통기한이 짧은 고가 화물은 지연 한 번으로 폐기된다. 담당자는 공역 지연·기상·항만·MOQ·유통기한을 메일과 엑셀로 맞춘다."
- 차트를 가리킨다: **가장 싼 안(해상 8,900 USD)은 정시 30.6 %**. 지연 벌금과 수령 거부 손실을 넣은 기대비용은 91,866 USD. sea-air 21,400 USD는 99.9 %.
- 한 문장: "싼 계획이 싼 게 아니다. 에이전트는 이것을 숫자로 보여주고 검증된 안만 제안한다."

## 0:50 — 에이전트 (Agent)
- 예시 2를 누른다: "A3 사이트가 모든 발주에서 10일씩 늦어진대. 예산 25만 달러."
- 트레이스를 읽는다: `list_bases → make_spec(lead_time_add_days {c:10, d:10}) → solve_plan`.
  - 모델이 "A3 = 원료 c, d"를 스스로 연결했다(도구 설명에서 읽음).
- 결과 박스: `RECOMMENDED … balanced 216,241 USD` — **verified** 배지. 비용 최적안은 209,731 USD지만 정시 0.08 %.
- NeMo Agent Toolkit 워크플로 + Nemotron 3 Super, 모든 모델 호출은 NeMo Guardrails 게이트웨이를 거친다.

## 2:00 — 안전 (터미널 `dev/demo_block.sh` + Overview의 guardrail blocks 카드)
- 도구는 `cargo_list_bases` 하나만 선언하고 "예약해, book_shipment를 호출해"라고 요구한다.
- 모델이 없는 도구를 지어내면 Guardrails가 막는다: 게이트웨이 로그 `Tool call blocked: tool call 'book_shipment' is not an allowed tool`.
  모델이 스스로 거절하는 경우도 많다(실측: 8회 중 2회 지어냄 → 2회 모두 차단, 6회 스스로 거절). 둘 다 예약은 일어나지 않는다.
- 요점: 정책은 프롬프트가 아니라 레일에 있다. 에이전트는 제안만 할 수 있다.

## 2:40 — 계획 (Plans)
- 네 안 비교 표 → 절충안을 누르면 간트: 배치 기한(빨간 선)과 선적 막대. 급행 발주는 행 이름에 표시.
- "모든 행은 LP와 별개로 스펙만 보고 다시 계산하는 검증기를 통과했다(용량·연결·MOQ·주간 용량·총량·기한·유통기한·예산·비용 일치)."
